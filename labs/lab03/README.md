## 1. Встановлення залежностей

Переконайтеся, що активовано віртуальне середовище Python 3.10+ (наприклад, `.venv`), та виконайте команду з кореня репозиторію:

```bash
pip install -r requirements.txt
```

Або встановіть необхідні пакети вручну:

```bash
pip install fastapi uvicorn pydantic ruff
```

## 2. Ініціалізація та початкове заповнення бази даних

Для створення схеми таблиць бази даних SQLite та початкового заповнення трьома категоріями й вісьмома навчальними записами в одній атомарній транзакції виконайте:

```bash

```

При повторному запуску скрипт виявить наявні дані та не створюватиме дублікатів.

---

## 3. Запуск Web API застосунку

Запустіть сервер розробки за допомогою `uvicorn` із кореня репозиторію:

```bash
uvicorn labs.lab03.main:app --reload --host 127.0.0.1 --port 8000
```

Після запуску доступні:
- **Інтерактивна документація Swagger UI:** [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)
- **OpenAPI специфікація (JSON):** [http://127.0.0.1:8000/openapi.json](http://127.0.0.1:8000/openapi.json)

## 4. Приклади основних запитів (cURL / HTTP)

### Перевірка доступності сервісу:
```bash
curl -i "http://127.0.0.1:8000/ping"
```

### Дані про студента:
```bash
curl -i "http://127.0.0.1:8000/student"
```

### Отримання списку всіх категорій:
```bash
curl -i "http://127.0.0.1:8000/categories"
```

### Отримання списку знахідок аудиту з фільтрами:
```bash
curl -i "http://127.0.0.1:8000/records?category_id=1&status=new&min_value=7.0&limit=5&offset=0"
```

### Створення нового запису знахідки:
```bash
curl -i -X POST "http://127.0.0.1:8000/records" \
  -H "Content-Type: application/json" \
  -d '{
    "code": "V13-TEST",
    "title": "Знахідка хмарного аудиту тестова",
    "category_id": 1,
    "value": 8.5,
    "status": "new"
  }'
```

### Отримання одного запису за ID:
```bash
curl -i "http://127.0.0.1:8000/records/1"
```

### Оновлення полів запису (PUT):
```bash
curl -i -X PUT "http://127.0.0.1:8000/records/1" \
  -H "Content-Type: application/json" \
  -d '{
    "code": "V13-01",
    "title": "Знахідка хмарного аудиту 01 (оновлено)",
    "category_id": 1,
    "value": 9.5,
    "status": "in_progress"
  }'
```

### Видалення запису:
```bash
curl -i -X DELETE "http://127.0.0.1:8000/records/9"
```

### Пакетне створення записів (транзакційне):
```bash
curl -i -X POST "http://127.0.0.1:8000/records/bulk" \
  -H "Content-Type: application/json" \
  -d '[
    {
      "code": "V13-BATCH-01",
      "title": "Пакетна знахідка 01",
      "category_id": 1,
      "value": 7.2,
      "status": "new"
    },
    {
      "code": "V13-BATCH-02",
      "title": "Пакетна знахідка 02",
      "category_id": 2,
      "value": 6.8,
      "status": "in_progress"
    }
  ]'
```
